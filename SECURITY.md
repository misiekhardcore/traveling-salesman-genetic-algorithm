# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities seriously and appreciate responsible disclosure.

If you discover a security vulnerability in this project, please report it by:

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Contact us privately via email at [konopskiwebdev@gmail.com](mailto:konopskiwebdev@gmail.com)
3. Include detailed information about the vulnerability and steps to reproduce

We will respond to your report within 48 hours and work with you to address the issue promptly.

## Scope

- Source code in this repository
- CI/CD workflows and configuration
- Development dependencies and tooling

## Preferred Languages

We prefer all communications to be in English.

## Disclosure Policy

- We will acknowledge your report within 48 hours
- We will keep you informed of our progress towards a fix and disclosure
- We will credit you in the release notes if desired (optional)
